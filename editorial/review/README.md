# Pilot til gjennomgang

[Åpne PDF-en](pilot-til-gjennomgang.pdf). Den inneholder hele pilotanalysen, tre grafer, årstabell, metode, kilder, begrensninger og LinkedIn-utkast. Den redaksjonelle revisjonen lar leseren følge fra observasjon i grafene via spørsmål til tolkning. LinkedIn-utkastet har en kortere, mildt humoristisk inngang og inviterer til å utforske tidsforløpet.

PDF-en er eksportert på nytt fra artikkelens lokale forhåndsvisning etter innspillet om redaksjonell formulering, og er merket **Utkast** på hver side. Grafene og tallgrunnlaget er beholdt. Innholdsversjon: `145f833b3df102a36ac370fa6f3819b3ae12685e853da40b90b21923117b6ece`. Kildeutkastet er [pilot.json](../drafts/pilot.json); en tekstversjon finnes i [pilot.md](../drafts/pilot.md).

Bruk PDF-en til å vurdere innhold og sende endringsønsker i vanlig språk. Endringer gir en ny innholdsversjon og krever en oppdatert gjennomgang. PDF-en er ingen registrert publiseringsgodkjenning; publisering bruker den aktuelle GitHub-versjonen og den ansvarlige godkjennerens review.

Dokumentet ligger utenfor `web/public` og inngår ikke i nettstedets produksjonsbygg. Det deles til gjennomgang via GitHub på arbeidsgrenen. Tilgang til filen følger repositoryets innstillinger.
