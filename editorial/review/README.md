# Pilot til gjennomgang

[Åpne PDF-en](pilot-til-gjennomgang.pdf). Den inneholder hele pilotanalysen, tre grafer, årstabell, metode, kilder, begrensninger og LinkedIn-utkast. Revisjonen viser tidsforløpet tydeligere og vurderer hva resultatet kan antyde.

PDF-en er eksportert på nytt fra artikkelens lokale forhåndsvisning etter innspillet om flere grafer og tydeligere tolkning, og er merket **Utkast** på hver side. Innholdsversjon: `2d514e5de478a0e003c48e4b4ba2f9722ad1384fc8cf3a263143ff0b6c1a2c3a`. Kildeutkastet er [pilot.json](../drafts/pilot.json); en tekstversjon finnes i [pilot.md](../drafts/pilot.md).

Bruk PDF-en til å vurdere innhold og sende endringsønsker i vanlig språk. Endringer gir en ny innholdsversjon og krever en oppdatert gjennomgang. PDF-en er ingen registrert publiseringsgodkjenning; publisering bruker den aktuelle GitHub-versjonen og den ansvarlige godkjennerens review.

Dokumentet ligger utenfor `web/public` og inngår ikke i nettstedets produksjonsbygg. Det deles til gjennomgang via GitHub på arbeidsgrenen. Tilgang til filen følger repositoryets innstillinger.
